# SkillProof — Фазовые промпты (переход на анонимный PIN + аудит безопасности)

Большой промпт разбит на 6 самодостаточных фаз. Запускай их **строго по порядку** — каждая
опирается на результат предыдущей.

## Как пользоваться
1. Открой файл нужной фазы.
2. Вставь в v0 сначала содержимое `00-context.md` (роль, цель, жёсткие ограничения), затем —
   содержимое файла фазы.
3. Дождись выполнения и краткого отчёта по изменённым файлам.
4. Только после этого переходи к следующей фазе.

## Порядок фаз
| # | Файл | Что делает |
|---|------|------------|
| 0 | `00-context.md` | Общая шапка: роль, цель, ограничения (вставлять перед каждой фазой) |
| 1 | `phase-1-data-model-pin.md` | Схема БД: удаление ПДн, таблица `candidates`, PIN (hash + HMAC-lookup), миграция |
| 2 | `phase-2-start-page-no-pii.md` | Стартовая страница без имени/email, ввод и регистрация PIN, гейт попыток |
| 3 | `phase-3-certificate-recovery.md` | Восстановление сертификата по PIN, обезличивание сертификата и `/verify` |
| 4 | `phase-4-admin-stats.md` | Исправление статистики админки, метрики, замена ПДн-колонок на PIN |
| 5 | `phase-5-security.md` | Rate-limit против перебора PIN, защита прокторинга, заголовки, аудит-меры |
| 6 | `phase-6-regression-report.md` | Регресс-проверка и финальный отчёт |

## Зачем разбивать
- Меньше риск, что модель «срежет углы» на длинном задании.
- После каждой фазы — контрольная точка и отчёт, легко откатиться.
- Каждый файл самодостаточен (с общей шапкой), можно переиспользовать и править по отдельности.
