# ФАЗА 6 — РЕГРЕСС И ОТЧЁТ

> Сначала вставь общий контекст из `prompts/00-context.md`, затем — задание ниже.
> Предусловие: Фазы 1–5 завершены.

## Проверь и подтверди
- На стартовой странице нет полей имени и email; есть только ввод 4-значного PIN и блок
  восстановления сертификата.
- Два пользователя не могут зарегистрировать одинаковый PIN (UNIQUE на `pin_lookup`; проверь
  параллельные вставки).
- Слабые PIN отклоняются; PIN не хранится в открытом виде; PIN не появляется в URL и логах.
- Полный проход теста работает: 10 вопросов (7+3), прокторинг, прерывание при 3 нарушениях,
  сертификат, QR, `/verify`, PDF.
- Восстановление сертификата по PIN возвращает сертификат; по несуществующему PIN — нейтральное
  «не найдено»; перебор блокируется rate-limit'ом.
- В админке: статистика считается по уникальным значениям, метрики (конверсия, средний балл,
  доля чистых, нарушения на попытку) отображаются; ПДн нигде нет.
- ChallengeGate, специализация «Бухгалтер» и канон теста не затронуты.
- В БД не осталось ни одной колонки/строки с персональными данными.
